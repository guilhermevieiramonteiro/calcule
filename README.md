🧮 Calculadora Básica
Uma aplicação simples de calculadora desenvolvida para realizar operações matemáticas fundamentais. O projeto foi construído com o objetivo de praticar conceitos básicos de desenvolvimento de software, estrutura de código e interface.

🚀 Funcionalidades
➕ Soma: Adição de dois ou mais números.

➖ Subtração: Subtração entre valores.

✖️ Multiplicação: Multiplicação simples.

➗ Divisão: Divisão com tratamento para divisão por zero.

🧹 Limpar (C/AC): Reseta os valores e limpa a tela.
